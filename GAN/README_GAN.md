## Overview

Real-world medical datasets frequently suffer from class imbalance, where one class is significantly underrepresented. This project investigates two GAN architectures — Vanilla GAN (DCGAN) and Conditional GAN (CGAN) — to generate realistic synthetic chest X-ray images for the minority class (Normal), then evaluates how GAN-based balancing affects downstream classification performance.

## Methodology

### 1. GAN Training

Both GAN models were trained exclusively on the minority class (NORMAL) to generate synthetic samples that augment the underrepresented class without altering the majority class distribution.

#### DCGAN (Vanilla GAN)

- **Generator:** Takes a random noise vector (latent dim = 100) and progressively upsamples through transposed convolutional layers to produce a 64×64 grayscale image
- **Discriminator:** Convolutional layers progressively downsample the input and predict real vs. synthetic
- **Loss:** Binary Cross-Entropy with Logits

#### CGAN (Conditional GAN)

- **Generator:** Receives both a noise vector and a class label embedding, concatenated before passing through the same transposed convolutional architecture
- **Discriminator:** Receives both the image and a spatial label map (concatenated as an additional channel), verifying image-label consistency

### 2. Dataset Balancing

After GAN training, 2,500 synthetic Normal images were generated by each model. The number of synthetic images needed to balance the training set was calculated as:

```
need = count(PNEUMONIA) - count(NORMAL)
```

Synthetic images were sampled from the respective GAN output and added to the NORMAL class folder, producing two balanced training sets: one for DCGAN and one for CGAN.

### 3. Classifier Training

A simple CNN classifier was trained on three different dataset configurations and evaluated on the same held-out test set:

- Original imbalanced dataset
- Balanced using DCGAN synthetic images
- Balanced using CGAN synthetic images

## Classifier Architecture (SimpleCNN)

```
Conv2d(1, 16)  → ReLU → MaxPool2d(2)   # 32×32
Conv2d(16, 32) → ReLU → MaxPool2d(2)   # 16×16
Conv2d(32, 64) → ReLU → MaxPool2d(2)   #  8×8
Flatten
Linear(64×8×8, 128) → ReLU → Dropout(0.3)
Linear(128, 2)
```

## Results

| Scenario | Accuracy | Precision | Recall | F1-Score | AUC-ROC |
|----------|----------|-----------|--------|----------|---------|
| Imbalanced (Original) | 0.74 | 0.72 | 0.98 | 0.83 | 0.87 |
| Balanced (DCGAN) | 0.75 | 0.72 | 0.99 | 0.83 | 0.86 |
| **Balanced (CGAN)** | **0.80** | **0.77** | **0.98** | **0.86** | **0.88** |

### Key Findings

- The original imbalanced dataset achieved high recall (0.98) for Pneumonia but suffered from lower precision (0.72), reflecting a bias toward the majority class
- DCGAN-based balancing preserved high recall but provided limited improvement in overall classification performance
- CGAN-based balancing achieved the best results across all metrics: highest accuracy (0.80), precision (0.77), F1-score (0.86), and AUC-ROC (0.88), while maintaining competitive recall (0.97)
- Conditional GANs produced higher-quality, class-aware synthetic samples that improved class discrimination without sacrificing sensitivity to Pneumonia cases
