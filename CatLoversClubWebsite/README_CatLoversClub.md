# Cat Lovers Club — University of Jordan

A static website for the Cat Lovers Club (CLC) at the University of Jordan, built as a group project for the Ethics and Human Values course. The club was founded by students who share a love for cats and a concern for the stray cats on campus.

---

## Overview

The website serves as the online presence for the Cat Lovers Club at the University of Jordan. It provides information about the club, how to get in touch, where to find the club on campus, and a list of club members.

---

## Pages

| File | Page | Description |
|------|------|-------------|
| `index.html` | Home | Landing page with hero image, club overview, how to join, and campus locations summary |
| `About_Us.html` | Get In Touch | Contact information and social media links |
| `Our_locations.html` | Our Locations | Google Maps links to cat locations across campus |
| `Members_list.html` | Our Team | List of club members |

## How to Run

This is a static website with no dependencies to install. Simply open `index.html` in any web browser to view it locally, or host it on any static hosting service such as GitHub Pages.
